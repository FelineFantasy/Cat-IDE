# 🖥️ Cat IDE

A simple Python IDE built with customtkinter. Write code, run it with F5. No bloat, just cat power.

## 📝 Description

Cat IDE is a lightweight code editor with dark theme. Press F5 or click ▶ to execute your Python code instantly.

### Features:
- 🎨 Dark theme
- ⌨️ F5 to run, Ctrl+S to save
- 📦 Single file — `cat_ide.py`
- 🐱 Zero bloat

## ⚙️ Installation

```bash
pip install -r requirements.txt
```

## 🎮 Usage

```bash
python cat_ide.py
```

## 📦 Hotkeys


| Key | Action |
| :--- | :--- |
| **F5** | Run code |
| **Ctrl+S** | Save file |
